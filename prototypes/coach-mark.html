Coach mark

A dismissible callout that spotlights a new feature and points at the UI element it relates to. Built as a self-contained Web Component (<ap-coach-mark>) using Shadow DOM, so its styles cannot leak into — or be affected by — a host page's CSS, and it has zero external dependencies. Copy the full source below and drop it into any third-party page — the tag becomes available with nothing else to install.
